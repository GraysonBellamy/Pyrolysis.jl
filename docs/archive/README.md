# Archived Documents

Retained records that are not authoritative design docs but are kept for
provenance and as calibration anchors.

| File | What it is |
|------|------------|
| `wp_capa_measurements.md` | Canonical record of White Pine UMD CAPA N₂ cone-test pre/post measurements (2026-04-30). Used as calibration anchors for the variable-cross-section model and inverse-fit conductivities. |

The historical pre-refactor design and planning memos (ALE framework,
implementation plan, hybrid discretization, Jacobian scoping, sensitivity
plan, Phase 7 verb audit, Kirchhoff correction handoff, transpiration BC
analysis) have been removed: their intent is now realized in the codebase
(`src/`, `examples/inverse_analysis/`) and their once-open work items are
resolved. See git history for the deleted versions.
