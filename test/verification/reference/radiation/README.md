# Radiation references

Numerical references for the radiation verification cases, each generated by
the script beside it. Both the verification suite's assert mode and its report
mode read these files.

| File | Generator | Read by |
|---|---|---|
| `vrad07_n50.csv`, `vrad07_n100.csv`, `vrad07_n200.csv`, `vrad07_n1600.csv` | `vrad07_reference.jl` | V-RAD-07 |

## V-RAD-07: an independent method of lines

`vrad07_reference.jl` solves V-RAD-07's slab without the package. It uses the
same discretization, written out separately:
- cell-centred finite volumes;
- the exposed face's convective balance in closed form;
- the radiation rows of `exact/two_stream.jl`, eliminated at every evaluation.

The reference is therefore an ordinary differential system in the cell
temperatures, where the solver carries the radiative fluxes as algebraic
unknowns. It is integrated by Kvaerno5 at reltol 1e-12 and checked against
FBDF at the same tolerance. The meshes of 50, 100 and 200 cells are saved
every 5 s to 180 s, for the same-mesh comparison. The 1600-cell mesh is saved
at 30, 60, 90 and 180 s and stands in for the continuum in the order check.

Each CSV has a names row and a units row, then one row per saved time: the
time [s], the surface temperature [K], and the cell temperatures [K] from the
back (cell 1, z = 0) to the exposed face.

Regenerate from the repository root:

    julia --project=test --startup-file=no test/verification/reference/radiation/vrad07_reference.jl

The committed files were generated with Julia 1.13.0, OrdinaryDiffEq 7.8.1 and
OrdinaryDiffEqSDIRK 2.9.6. That run printed:
